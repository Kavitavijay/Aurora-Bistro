# 🍽️ Aurora Bistro

A modern and responsive restaurant website built using **HTML, CSS, and JavaScript**. The project provides an interactive food ordering experience with menu browsing, shopping cart, checkout, and order confirmation.

## ✨ Features

- Responsive Design
- Interactive Navigation
- Live Menu Search
- Category Filters
- Add to Cart
- Shopping Cart Management
- Promo Code Support
- Checkout Page
- Order Success Page
- Local Storage
- Toast Notifications

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
- Google Fonts
- Local Storage API
